# 설계 결정 기록(ADR)

이 폴더는 되돌리기 어렵거나 여러 PR에 걸치는 결정을 한 문서에 하나씩 남긴다. 번호는 4자리(`0001-…`)로 순서대로 붙이고, 한 번 쓴 번호는 다시 쓰지 않는다. 결정이 바뀌면 문서를 지우지 않고 상태를 "대체됨(→ 새 번호)"으로 바꾼 뒤 새 문서를 쓴다.

| 번호 | 제목 | 상태 |
|---|---|---|
| [0001](0001-narrative-canonical-wording.md) | 소견서·EMR 서술 문구의 정본 | 결정됨(2026-11-26) — 구현 완료(P2-66a ~ P2-66f, 2026-11-27) · 추가 결정(2026-11-27, 출력의 빈 직종명) 구현 완료(P2-72h, 2026-11-28), 운영 반영은 R2b |

## 템플릿

```markdown
# NNNN. 제목

- 상태: 제안 | 결정 대기 | 결정됨(YYYY-MM-DD) | 대체됨(→ NNNN)
- 관련: 로드맵 항목·PR·계획 문서

## 배경
무엇을 정해야 하는지, 왜 지금인지.

## 선택지
각 선택지와 그 결과(바뀌는 출력·동작, 되돌리는 방법).

## 결정
고른 것과 이유. 사용자 결정이면 날짜와 함께 적는다.

## 결과
이 결정으로 할 일(PR)과 하지 않기로 한 일.
```
